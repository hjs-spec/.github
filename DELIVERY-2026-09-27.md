## Repairs and evidence

[CLI #7](https://github.com/hjs-spec/cli/pull/7) unifies inline/file/stdin parsing, rejects duplicate members and extension arguments, malformed Unicode/UTF-8, non-finite values and unsupported precision-losing integers. It preserves supported JCS numeric forms and explicit legacy selection. Existing and new tests: **57 passed** in [PR CI](https://github.com/hjs-spec/cli/actions/runs/36289207495). Released source is `33c5053a6e24b6b940d7ccdf1919123c8ef7a4e8`.

[Go SDK #7](https://github.com/hjs-spec/sdk-go/pull/7) checks original bytes before `encoding/json` can merge members or replace malformed text. Thirteen hostile-input subcases, valid-member preservation and five fuzz seeds passed alongside retained tests; local and hosted `go test -race -count=1 ./...` passed. [PR CI](https://github.com/hjs-spec/sdk-go/actions/runs/36289290244). Released source is `f6712380988fcda27a07abd0d61bed0a6eb1d9ca`. This is transport validation, not independent cryptographic verification.

[Core #32](https://github.com/hjs-spec/jep-core/pull/32) pins the current gate to actual release commits and includes CLI tests. The published Binding/02 historical reproduction pin is untouched.

- [Current release interoperability](https://github.com/hjs-spec/jep-core/actions/runs/36289691654): 11 signed events, five transport paths, **55 exact signature/hash roundtrips**, four verifier implementations, **50 Binding/02 structural/reference checks**.
- [Core current/legacy conformance](https://github.com/hjs-spec/jep-core/actions/runs/36289693770): passed, including frozen-publication checks.
- [Registry download and clean install](https://github.com/hjs-spec/jep-core/actions/runs/36289691640): eight Python release files independently redownloaded from both PyPI and GitHub, SHA-256 compared against both metadata records and actual bytes. Five supplemental GitHub files checked. Four Python wheels installed with dependencies in an isolated, fresh Python 3.12 environment.
- Installed smoke: J/D/T/V signatures accepted by Core and SDK; four Core/SDK/CLI transport checks; eight tamper rejections; eighteen malformed-input rejections; missing-key indeterminate; accepted/already-accepted/identity-conflict behavior. No production state or credentials used.

The initial installed-smoke fixture used a string-valued V scope and was correctly rejected. The fixture was corrected to the required array shape; no verifier rule was weakened. Final checks above passed. stderr and the installed dependency list are now retained on both success and failure.

[Python SDK #6](https://github.com/hjs-spec/sdk-py/pull/6) reconciles the GitHub v0.7.0 release description with the already corrected source notes. [Metadata reconciliation](https://github.com/hjs-spec/sdk-py/actions/runs/36289817852) passed; release identity, tag, publication date and artifact digests were checked unchanged.
