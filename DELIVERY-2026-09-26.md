The [0.7.2 GitHub release](https://github.com/hjs-spec/jep-core/releases/tag/v0.7.2) is complete. [PyPI publication](https://github.com/hjs-spec/jep-core/actions/runs/36244149489) failed with `invalid-publisher`: the OIDC token was valid but no publisher matched it.
