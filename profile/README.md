# JEP · Judgment Event Protocol

Signed statements of **Judgment, Delegation, Termination and Verification**.
JEP records claims and the checks performed on them. A signature alone does not establish truth, authority, legal effect or complete logging.

Current protocol: **Core 0.7**, wire major `jep: "1"`. Software versions are independent. The published Internet-Draft -07 is frozen; historical formats use explicit compatibility paths.
